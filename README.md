## 这是什么

河流流域的土壤墒情是**防汛抗旱、灌区调度与农业生产**的共同基础数据。这类测点通常沿河道呈带状分布——岸坡农田、河滩地、阶地、支流汇入口各需代表性点位，彼此相距数百米到数公里，且多位于**无市电、无光纤、手机信号不稳定**的野外环境。

这一空间形态决定了两件事：

- **通信必须自建** —— 公网靠不住，所以用 LoRa 建私有低功耗无线传感网
- **供电必须自给** —— 没有市电，所以用太阳能 + 锂电，靠占空比而非低峰值功耗换续航

本仓库包含该系统的**完整设计方案**与**节点固件实现**。

## 系统架构

系统采用「感知层 — 汇聚层 — 应用层」三层结构。感知层与汇聚层之间为自建 LoRa 私有网，汇聚层以上走公网。

```
┌──────────────────────────────────┐
│      应用层（云端 / 本地）         │
│   墒情数据库 · 旱情分析 · 预警      │
└────────────────▲─────────────────┘
                 │ MQTT / SL 651（公网）
┌────────────────┴─────────────────┐
│   汇聚层：区域网关（常供电）        │
│  GD32F303 + SX1262 + 4G Cat.1    │
│  LoRa 接收 · 本地存储 · 断网续传   │
└───────▲──────────────────▲───────┘
        │ LoRa 470 MHz     │
┌───────┴────────┐  ┌──────┴─────────┐
│  感知层 节点 #1 │  │  感知层 节点 #N │
│ GD32L233+SX1262│  │ GD32L233+SX1262│
│ 4层墒情 + 雨量  │  │ 4层墒情 + 雨量  │
│ 太阳能 + 锂电   │  │ 太阳能 + 锂电   │
└────────────────┘  └────────────────┘
   （沿流域带状布设；超距断面插入中继节点）
```

### 三个关键设计取舍

| 约束 | 内容 | 带来的设计 |
|---|---|---|
| **法规** | 470 MHz 属微功率短距离频段，依工信部 2019 年第 52 号公告免许可，但不得擅自加大功率 | 模块标称 +22 dBm 必须**降额到 +17 dBm** 使用，链路预算按 +17 dBm 算 |
| **能量** | 节点无市电，发射瞬时 100 mA vs 休眠 µA 级，差四个数量级 | **占空比决定续航**，不是峰值功耗。60 min 周期下平均电流 57 µA |
| **传播** | 天线受埋设条件限制只能架到 4 m 左右，属低空链路 | 地面反射形成干涉衰落，**覆盖半径不能按自由空间公式外推**，须叠加衰落余量 |

> **为什么不用 Mesh**：转发要求节点长期开启接收窗，平均电流会从 µA 级跃升到 mA 级，续航从**年**降到**月**。因此主拓扑取星型，仅在个别超距断面插入**常供电**中继——这是本方案与"通用 Mesh 宣传"最重要的分歧。

## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/niuruifeng2-tech/gd32-lora-basi.git
cd gd32-lora-basi
```

### 2. 打开工程

用 **Keil MDK 5** 打开：

```
code/project/STM32F103ZET6_Project.uvprojx
```

> 工程内所有源文件均以 `..\libraries\`、`..\RT_Thread\` 等**相对路径**引用，
> 因此整个 `code/` 目录可任意移动位置，工程仍能正常打开。

### 3. 编译与烧录

- 编译器：ARMCC V5.06 update 5（Keil MDK 5.24 及以上）
- 调试器：ST-Link（SWD 模式）
- 目标芯片：STM32F103ZET6（512 KB Flash / 64 KB RAM）

### 4. 串口验证

| 参数 | 值 |
|---|---|
| 串口 | USART1（板载 CH340） |
| 波特率 | 9600 |
| 数据位 / 校验 / 停止位 | 8 / 无 / 1 |

## 硬件平台

### 核心器件

| 环节 | 选型 | 选型理由 |
|---|---|---|
| **节点 MCU** | GD32L233RCT6 | Stop 电流 < 2 µA、Standby < 0.4 µA，直接决定续航；内置 Segment LCD 控制器与硬件加密单元 |
| **网关 MCU** | GD32F303 | 120 MHz Cortex-M4，需同时跑 LoRa 驱动、4G AT 交互、文件系统与协议栈 |
| **射频** | SX1262（470 MHz） | 支持 SF5~SF12，链路预算充裕，功耗优于 SX1278 |
| **墒情传感器** | 三合一土壤温湿度电导率变送器 | RS485/Modbus 输出，FDR 原理，可长期埋设 |
| **雨量计** | 翻斗式 | 脉冲输出，可作事件唤醒源 |

### 传感器供电注意

三合一变送器供电为 **12~24 V**，这一点常被忽略：节点若用 3.7 V 锂电，必须增加升压电路，而升压电路的效率与静态电流会**直接吃掉续航**。

本方案的处理：**仅在采样时刻给传感器上电**，上电后等待稳定时间再读数，采样完成立即断电。

### 功耗关键指标

| 项目 | 数值 |
|---|---|
| 上报周期 | 60 min（可配置） |
| 平均电流 | **57 µA** |
| 理论续航 | 以**年**计 |
| 发射功率 | +17 dBm（法规降额后） |
| 链路预算 | 见 [docs/系统设计方案.md](docs/系统设计方案.md) 第 5 章 |
