## 2 从机引脚分配

| 功能 | 引脚 | 外设/模式 | 备注 |
|---|---|---|---|
| **雨滴 DO** | **PC1** | 上拉输入 | 1 = 无水，0 = 有水 |
| **雨滴 AO** | **PC2** | 模拟输入 | ADC1_IN12，水越多电压越低 |
| **水位 AO** | **PA1** | 模拟输入 | ADC1_IN1，**需拔 P10 跳线帽** |
| DHT20 SCL | PB6 | 开漏输出 | 软件 I2C，**需 4.7K~10K 上拉** |
| DHT20 SDA | PB7 | 开漏/浮空 | 软件 I2C，**需 4.7K~10K 上拉** |
| LoRa TXD→ | PB11 | USART3_RX | 模块 TXD 接单片机 RX |
| LoRa RXD← | PB10 | USART3_TX | 模块 RXD 接单片机 TX |
| LoRa MD0 | PB12 | 开漏输出 | 模式选择低位 |
| LoRa MD1 | PB13 | 开漏输出 | 模式选择高位 |
| LoRa AUX | PB14 | 浮空输入 | 模块忙/闲状态 |
| 调试串口 | PA9/PA10 | USART1 | 9600 8N1，接 PC |
| LED0 / LED1 | PB5 / PE5 | 推挽输出 | 低电平点亮 |
| 蜂鸣器 | PB8 | 推挽输出 | 从机未使用 |

> 从机不使用 DO 输出（PA4 区域），见 [§4.2](#42-水位传感器)。

## 4 传感器接线

### 4.1 雨滴传感器

```
模块                 STM32
┌──────┐
│ VCC  │──────────── 3.3V
│ GND  │──────────── GND
│ DO   │──────────── PC1
│ AO   │──────────── PC2
└──────┘
```

**信号特征**：

| 输出 | 干燥 | 有雨 |
|---|---|---|
| DO | 高电平（1） | 低电平（0） |
| AO 电压 | 高（~2.4V） | 低（水越多越低） |
| AO ADC | **2900~3500**（实测） | 明显下降 |

**实测数据**：干燥时 ADC 2895~3500，滴水后明显下降。

### 4.2 水位传感器

**XPT2046 液位转换板**

```
模块                 STM32
┌──────┐
│ VCC  │──────────── 5V        ← 注意是 5V，不是 3.3V！
│ GND  │──────────── GND
│ AO   │──────────── PA1       ← 必须拔掉 P10 跳线帽！
│ DO   │──────────── 不接      ← 本工程只用 AO
└──────┘
```

**信号特征**：

| 项 | 值 |
|---|---|
| AO 电压范围 | 0 ~ 1.0V 对应液位 0% ~ 100% |
| AO 最高电压 | 1.0V（远低于 STM32 ADC 输入上限 3.3V，**可直接接入，无需分压**） |
| 与液位关系 | **非线性**，需门限表换算 |
| 实测空水 ADC | ≈ 20 |
| 实测满水 ADC | ≈ 716（显示 80%） |

> **为什么不用 DO**：参考例程把 DO 接 PA4，但 PA4 是 DAC_OUT1 / WIFI复位 / 蓝牙EN，
> 属于无线模块接口区，容易和 LoRa 模块干涉。本工程只用 AO，水位判定完全靠 ADC 换算。

### 4.3 DHT20 温湿度（仅从机）

```
模块                 STM32
┌──────┐
│ VCC  │──────────── 3.3V
│ GND  │──────────── GND
│ SCL  │──────────── PB6  ← 需 4.7K~10K 上拉到 3.3V
│ SDA  │──────────── PB7  ← 需 4.7K~10K 上拉到 3.3V
└──────┘
```

| 项 | 值 |
|---|---|
| 通信方式 | 软件模拟 I2C |
| 器件地址 | 0x38 |
| 上拉电阻 | **必须 4.7K~10K**（模块自带可不加） |
| 测量耗时 | ~100 ms |

> **DHT20 与板载 AT24C02 共用 PB6/PB7**：AT24C02 地址 0x50，DHT20 地址 0x38，地址不冲突。
> 两者都是开漏 I2C 器件，本工程只在主循环顺序访问，不并发，安全。
> DHT20 驱动内部有 `Bus_Recover()`，总线被拉死也能自行恢复。

## 5 LoRa 模块接线

**AS32-TTL-100-C**

```
模块                 STM32（两机相同）
┌──────┐
│ VCC  │──────────── 3.3V~5V（发射瞬间需 200mA）
│ GND  │──────────── GND
│ TXD  │──────────── PB11    ← 模块 TXD 接 MCU RX
│ RXD  │──────────── PB10    ← 模块 RXD 接 MCU TX
│ MD0  │──────────── PB12
│ MD1  │──────────── PB13
│ AUX  │──────────── PB14
└──────┘
```

### 引脚方向说明

| 模块引脚 | 接到 MCU | 说明 |
|---|---|---|
| **TXD** | **PB11**（USART3_RX） | 模块**发**，MCU **收** |
| **RXD** | **PB10**（USART3_TX） | 模块**收**，MCU **发** |

> **⚠️ 极易接反**：模块 TXD 要接 MCU 的 RX，模块 RXD 要接 MCU 的 TX。
> 接反的现象是 `LORA CONFIG READ FAIL`。

### 工作模式

| MD1 | MD0 | 模式 |
|---|---|---|
| 0 | 0 | **一般工作模式（透明传输）** ← 本工程使用 |
| 0 | 1 | WOR 发送模式 |
| 1 | 0 | WOR 接收模式 |
| 1 | 1 | **配置模式**（读写参数） |

程序启动时拉低 MD0/MD1 进入一般模式，读写配置时临时切到配置模式。

### 双端参数必须一致

| 参数 | 值 |
|---|---|
| 地址 | 0x0000 |
| 信道 | 0x3D（471MHz） |
| 串口 | 9600 8N1 |
| 空中速率 | 2.4 kbps |
| 模式 | 透明传输 |

> **注意型号**：AS32-TTL-100-C 出厂信道 **0x3D（471MHz）**，
> AS32-TTL-100 是 **0x17（433MHz）**，两者不通用。

## 6 OLED 接线

**0.96" SSD1306，128×64，4 线 I2C**（仅主机）

```
模块                 STM32
┌──────┐
│ VCC  │──────────── 3.3V
│ GND  │──────────── GND
│ SCL  │──────────── PB6   ← 必须 4.7K~10K 上拉到 3.3V
│ SDA  │──────────── PB7   ← 必须 4.7K~10K 上拉到 3.3V
└──────┘
```

| 项 | 值 |
|---|---|
| 驱动 IC | SSD1306 |
| 分辨率 | 128 × 64 |
| I2C 从机地址 | **0x3C** |
| 上拉电阻 | **必须 4.7K~10K** |

> **地址说明**：模块资料常标称 `0x78`，那是 **8 位写法**（含读写位）。
> 代码里用的是 7 位地址：`0x78 >> 1 = 0x3C`。
> 定义在 `code/master/user/api/i2c.h` 的 `OLED_ADDR`。

## 7 关键注意事项

### 7.1 ⚠️ 水位传感器必须拔 P10 跳线帽

**PA1 在开发板上兼作 TPAD 触摸检测脚。**

```
不拔 P10：PA1 被 TPAD 电路干扰 → 水位读数乱跳 / 不准
拔掉 P10：PA1 独立，读数正常
```

这是**最常见**的接线问题。

### 7.2 ⚠️ 水位传感器必须 5V 供电

```
❌ VCC 接 3.3V → 输出幅度不足，满水 ADC 只有 400 左右（显示 60%）
✅ VCC 接 5V   → 输出正常，满水 ADC 可达 716+（显示 80%）
```

> AO 最高只输出 1.0V，远低于 STM32 的 3.3V 输入上限，**5V 供电不会烧 MCU**。

### 7.3 ⚠️ I2C 必须加上拉电阻

DHT20（从机）和 OLED（主机）都走 PB6/PB7 软件 I2C。

**开漏输出必须有上拉才能输出高电平**，否则总线一直是低电平，通信全失败。

| 情况 | 处理 |
|---|---|
| 模块自带 4.7K 上拉 | 可直接用 |
| 模块无上拉 | **必须在 SCL/SDA 各接 4.7K~10K 到 3.3V** |

### 7.4 ⚠️ LoRa 模块 TXD/RXD 不要接反

见 [§5](#5-lora-模块接线)。接反 → `LORA CONFIG READ FAIL`。

### 7.5 检查 P5 跳线帽

开发板的 P5 跳线帽决定串口/无线模块的选择。
**必须选到无线模块**，否则 USART3 连不到 LoRa 模块。

### 7.6 雨滴传感器 PC0 悬空问题（历史记录）

早期版本用 PC0（ADC1_IN10），实测 ADC 恒为 4095（悬空），已改用 **PC2**。

## 8 供电

| 设备 | 电压 | 电流 | 备注 |
|---|---|---|---|
| STM32F103ZET6 | 3.3V | ~50mA | 板载 LDO |
| LoRa 模块（待机） | 3.3~5V | ~10mA | |
| LoRa 模块（发射） | 3.3~5V | **~200mA（瞬时）** | 供电要足，否则发射失败 |
| 雨滴传感器 | 3.3V | ~5mA | |
| 水位传感器 | **5V** | ~10mA | |
| DHT20 | 3.3V | ~1mA | |
| OLED | 3.3V | ~20mA | |

> **LoRa 发射瞬时 200mA** 是供电设计的关键约束。
> 如果用 USB 供电且线材细，发射瞬间可能电压跌落导致丢包，建议用短粗线或独立 5V 电源。

## 9 接线检查清单

上电前逐项确认：

### 从机

- [ ] 雨滴 VCC→3.3V，GND→GND，DO→PC1，AO→PC2
- [ ] 水位 VCC→**5V**，GND→GND，AO→**PA1**，DO 不接
- [ ] **水位传感器已拔 P10 跳线帽**
- [ ] DHT20 VCC→3.3V，SCL→PB6，SDA→PB7
- [ ] **DHT20 的 SCL/SDA 有 4.7K~10K 上拉**
- [ ] LoRa VCC→3.3V，GND→GND
- [ ] **LoRa 模块 TXD→PB11，RXD→PB10**（别接反）
- [ ] LoRa MD0→PB12，MD1→PB13，AUX→PB14
- [ ] **P5 跳线帽选到无线模块**
- [ ] 调试串口 PA9/PA10 接 USB 转 TTL

### 主机

- [ ] OLED VCC→3.3V，GND→GND，SCL→**PB6**，SDA→**PB7**
- [ ] **OLED 的 SCL/SDA 有 4.7K~10K 上拉**
- [ ] LoRa VCC→3.3V，GND→GND
- [ ] **LoRa 模块 TXD→PB11，RXD→PB10**（别接反）
- [ ] LoRa MD0→PB12，MD1→PB13，AUX→PB14
- [ ] **P5 跳线帽选到无线模块**
- [ ] 蜂鸣器 PB8（板载则无需接线）
- [ ] 调试串口 PA9/PA10 接 USB 转 TTL

### 双机联调

- [ ] **两块 LoRa 模块地址、信道、空中速率完全一致**
- [ ] 两块板子都已烧录对应固件
- [ ] 两机相距不要太近（< 1m 时信号过强可能反而收不到，拉开 2~3m 测试）
