## 文档约定

### 数据来源

文档中的量化结论分三类，请注意区分：

| 标记 | 含义 |
|---|---|
| **厂商规格** | 来自芯片/器件数据手册，可直接引用 |
| **计算得出** | 由公式推导，可复算（如链路预算、功耗模型） |
| **工程估计** | 基于经验，需现场验证（如衰落余量） |

### 未确认项

文档中标注「待确认」「需核对」的内容，**不可直接作为设计依据**，需查证后使用。例如：

- 标准号与条文阈值 —— 需核对现行有效版本
- U1/U5/U9 等未识别器件 —— 需查原理图确认

### 标准依据

引用的标准（GB/T 20481、SL 364、SL 651 等）**仅列出标准号**，具体条文阈值须查阅标准正文。本文档不替代标准。
