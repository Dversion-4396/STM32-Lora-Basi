## 快速导航

### 我是第一次接触这个项目

1. 先看 [系统设计](系统设计.md) 第 1~2 章，理解**两个节点各自干什么**
2. 再看第 4 章，理解**为什么主机要做拼帧**（这是本项目最大的坑）
3. 最后看 [通信协议](通信协议.md)，理解**帧长什么样**

## 文档约定

### 数据来源

文档中的量化结论分三类，请注意区分：

| 标记 | 含义 |
|---|---|
| **实测** | 本工程实际运行测得的数值（如 ADC 716、26.4℃） |
| **代码常量** | 直接来自源码宏定义，可 grep 验证 |
| **规格书** | 来自芯片/器件数据手册 |
| **估算** | 按时序/波特率推算（如 LoRa 发送 74ms），用于可行性判断 |

### 参数标注

所有参数都标注**所在文件**和**宏名**，可直接定位：

```
`master_app.h` → `WATER_ALARM_THRESHOLD` = 70
```

### 代码路径

文档中的路径均相对于仓库根目录：

```
code/slave/user/api/...     从机（感知节点）
code/master/user/api/...    主机（汇聚节点）
```
