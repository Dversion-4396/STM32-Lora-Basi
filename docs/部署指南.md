# 部署指南

> 流域布点原则、典型案例、实施里程碑与验收要点

---

## 1 流域布点原则

### 1.1 六条原则

| 原则 | 说明 |
|---|---|
| **沿河道纵向布设** | 覆盖上游、中游、下游不同断面，反映流域整体墒情梯度 |
| **地形代表性** | 岸坡、河滩、阶地、支流汇入口各需代表点，不能只选平坦好施工的地方 |
| **间距控制** | 开阔区 2 km、遮挡区 1 km、山地 0.8 km |
| **避开干扰** | 远离高压线、大功率发射源、金属结构物 |
| **可达性** | 便于安装与后期维护，但不要为了好到达而牺牲代表性 |
| **供电评估** | 评估日照条件，树荫、建筑阴影会显著降低发电量 |

### 1.2 间距设计依据

间距不是拍脑袋定的，来自链路预算（见 [系统设计方案 §5.2](系统设计方案.md#52-链路预算与覆盖半径量化)）：

| 地形 | 路径损耗指数 n | 可达距离 | 建议间距 |
|---|---|---|---|
| 开阔河滩（无遮挡） | 2.7 | 约 3.0 km | **2.0 km**（留余量） |
| 阶地灌木 / 作物季 | 3.2 | 约 1.0~1.5 km | **1.0~1.5 km** |
| 山地林区 | 3.8 | 约 0.8~1.0 km | **0.8~1.0 km** |

> **设计值取 2.0 km**，因为要取两个传播模型的交集，且需叠加 33 dB 的衰落余量。

## 2 典型案例：一个网关覆盖的测点布局

### 2.1 场景描述

某支流河段，长约 6 km，两岸为阶地农田，河滩有部分耕地，下游有支流汇入。

### 2.2 布点方案

```
        上游
          │
    ┌─────┴─────┐
    │  节点 #1   │  ← 河滩地，距网关 1.2 km
    │  10/20/40/60cm
    └───────────┘
          │
    ┌─────┴─────┐
    │  节点 #2   │  ← 岸坡农田，距网关 1.8 km
    └───────────┘
          │
    ┌─────┴─────┐         ┌──────────────┐
    │  节点 #3   │─────────│    网关      │  ← 阶地制高点
    └───────────┘  1.5 km │ 15 m 塔高     │     视野开阔
          │                │ 市电 + UPS   │
    ┌─────┴─────┐         └──────────────┘
    │  节点 #4   │  ← 支流汇入口，距网关 2.0 km
    └───────────┘
          │
        下游
```

### 2.3 覆盖评估

| 节点 | 距网关 | 地形 | 链路余量 | 判定 |
|---|---|---|---|---|
| #1 | 1.2 km | 河滩开阔 | 约 15 dB | ✅ 充裕 |
| #2 | 1.8 km | 岸坡农田 | 约 9 dB | ✅ 满足 |
| #3 | 1.5 km | 阶地 | 约 12 dB | ✅ 充裕 |
| #4 | 2.0 km | 支流汇入口 | 约 7 dB | ⚠️ 临界，建议 SF11 |

**结论**：4 个节点均在 2.0 km 设计半径内，**星型拓扑单网关即可覆盖**，无需中继。

## 3 实施阶段与里程碑

| 阶段 | 内容 | 交付物 | 周期 | 关键风险 |
|---|---|---|---|---|
| **P1 方案设计** | 需求分析、选型、链路预算 | 方案文档 | 2 周 | 需求理解偏差 |
| **P2 原型开发** | 节点硬件打样、固件框架 | 原型板 + 固件 | 6 周 | 硬件返工 |
| **P3 单点验证** | 室内测试、短距通信 | 测试报告 | 2 周 | 功耗不达标 |
| **P4 现场试点** | 3~5 个测点实地部署 | 试点数据 | 4 周 | 野外环境超预期 |
| **P5 标定优化** | 土壤标定、参数调优 | 标定报告 | 2 周 | 土壤类型差异 |
| **P6 规模部署** | 全流域布点 | 完整系统 | 8 周 | 施工协调 |
| **P7 验收运维** | 数据验收、运维培训 | 验收报告 | 2 周 | 数据完整性 |

**总周期约 26 周（半年）**，其中 P2 和 P6 是主要耗时环节。

## 4 安装工艺

### 4.1 墒情传感器埋设

| 步骤 | 要求 |
|---|---|
| 1. 开挖 | 挖至 80 cm 深剖面，保持原土层序 |
| 2. 分层标记 | 标记 10/20/40/60 cm 层位 |
| 3. 插入 | 传感器水平插入原状土，**避免留空隙** |
| 4. 回填 | 分层回填、分层压实，恢复原密实度 |
| 5. 电缆 | 穿管保护，接头做防水 |
| 6. 记录 | 拍照留档，记录埋设深度与朝向 |

> **最常见的错误**：挖坑后把土全部堆在一边，回填时随意填回，导致土层序被打乱、密实度不均，测出的墒情数据与实际不符。**必须分层开挖、分层回填。**

### 4.2 立杆安装

| 项目 | 要求 |
|---|---|
| 基础 | 混凝土基础，深度 ≥ 60 cm（冻土区需在冻深线以下） |
| 垂直度 | 偏差 < 2° |
| 高度 | 机箱离地 ≥ 1.5 m（防淹） |
| 天线 | 4 m 立杆，顶部固定 |
| 接地 | 独立接地极，接地电阻 < 4 Ω |
| 防雷 | 天线入口、电源入口、RS485 均需防护 |

### 4.3 太阳能板安装

| 项目 | 要求 |
|---|---|
| 朝向 | 正南（北半球） |
| 倾角 | 当地纬度 ± 5°（华北约 35~40°） |
| 遮挡 | 避开树荫、建筑阴影，考虑冬季太阳高度角 |
| 清洁 | 留出便于擦拭的空间 |
| 散热 | 背面留通风间隙 |

### 4.4 网关塔架

| 项目 | 要求 |
|---|---|
| 塔高 | 15 m（可覆盖约 24 km 视距） |
| 类型 | 拉线塔或自立塔，按风载选型 |
| 天线 | 玻璃钢全向，增益 3 dBi |
| 馈线 | 低损耗同轴（如 1/2" 馈管），损耗计入链路预算 |
| 防雷 | 避雷针保护角覆盖天线，接地电阻 < 4 Ω |
| 供电 | 市电 + UPS，或大功率太阳能 |

## 5 测试与验收

### 5.1 出厂测试

| 测试项 | 方法 | 合格标准 |
|---|---|---|
| 外观检查 | 目视 | 无损伤、标识清晰 |
| 通电自检 | 上电观察 | LED 指示正常 |
| 串口通信 | 连接 PC | 能正常输出 |
| 传感器读数 | 标准土样 | 误差 < ±3% |
| 发射功率 | 频谱仪 | +17 dBm ±1 dB |
| 频率误差 | 频谱仪 | ±10 ppm 内 |
| 功耗 | 库仑计 | 平均电流 < 60 µA |

### 5.2 现场验收

| 测试项 | 方法 | 合格标准 |
|---|---|---|
| **通信距离** | 逐步拉远，记录丢包率 | 2 km 内丢包 < 5% |
| **数据完整率** | 连续运行 30 天统计 | > 95% |
| **续航** | 实测电流积分 | ≥ 设计值 80% |
| **测量精度** | 与烘干法对比 | 误差 < ±3% |
| **防护等级** | 淋雨、浸水测试 | 内部无进水 |
| **高低温** | -40 ℃ / +70 ℃ 循环 | 功能正常 |
| **防雷** | 接地电阻测量 | < 4 Ω |
| **长期稳定性** | 连续运行 90 天 | 无死机、无漂移 |

### 5.3 数据质量评估

| 指标 | 计算方法 | 目标 |
|---|---|---|
| 数据完整率 | 实收帧数 / 应收帧数 | > 95% |
| 数据有效率 | 通过范围校验的帧数 / 实收帧数 | > 98% |
| 时延 | 采集时刻到入库时刻 | < 5 min |
| 一致性 | 相邻层含水率差值合理性 | 无突变 |

## 6 运维

### 6.1 日常巡检（建议每月）

- 检查太阳能板表面清洁度
- 检查立杆与拉线是否松动
- 检查机箱密封与防水
- 读取电池电压趋势
- 核对数据完整率

### 6.2 定期维护

| 周期 | 内容 |
|---|---|
| 每季度 | 清洁太阳能板、检查接线 |
| 每半年 | 传感器标定复检、电池容量测试 |
| 每年 | 全面检修、防雷接地测试、更换密封件 |
| 每 3 年 | 电池更换（按实测容量决定） |

### 6.3 故障处理

| 现象 | 可能原因 | 排查顺序 |
|---|---|---|
| 完全无数据 | 断电 / 天线断 / 模块坏 | ① 测电池电压 ② 看 LED ③ 测天线驻波 |
| 数据时有时无 | 链路临界 / 干扰 | ① 看 RSSI/SNR ② 提高 SF ③ 检查天线 |
| 墒情值异常 | 传感器故障 / 埋设松动 | ① 看状态位图 ② 现场复测 ③ 重新标定 |
| 电池电压持续下降 | 太阳能板被遮挡 / 板坏 | ① 清洁 ② 测开路电压 ③ 换板 |
| 数据重复 | 序号回绕 / 缓存重发 | ① 检查序号逻辑 ② 清缓存 |

## 8 风险与对策

| 风险 | 影响 | 概率 | 对策 |
|---|---|---|---|
| 4G 信号弱 | 数据丢失 | 高 | 本地缓存 + 断网续传；必要时改用北斗短报文 |
| 连续阴雨 | 电池耗尽 | 中 | 加大太阳能板冗余；降低上报频率 |
| 雷击损坏 | 设备报废 | 中 | 三级防雷；模块化可更换设计 |
| 传感器漂移 | 数据失真 | 高 | 定期标定；双传感器冗余 |
| 人为破坏 | 设备丢失 | 中 | 隐蔽安装；防盗固定；加装定位 |
| 牲畜踩踏 | 设备损坏 | 中 | 围栏保护；立杆加高 |
| 洪水淹没 | 设备报废 | 低 | 机箱离地 ≥ 1.5 m；选高处布点 |
| 标准变更 | 合规风险 | 低 | 设计前核对现行版本；预留调整空间 |

## 9 部署检查清单

### 9.1 安装前

- [ ] 确认测点位置与代表性
- [ ] 测量距网关距离，评估链路余量
- [ ] 确认日照条件（无遮挡时段）
- [ ] 确认土壤类型，准备标定曲线
- [ ] 设备出厂测试全部通过
- [ ] 准备工具、备件、防水材料

### 9.2 安装中

- [ ] 分层开挖、分层回填，恢复土层序
- [ ] 传感器与土壤紧密接触
- [ ] 立杆垂直度 < 2°
- [ ] 天线朝向与高度符合设计
- [ ] 太阳能板朝向与倾角正确
- [ ] 接地电阻实测 < 4 Ω
- [ ] 所有接头防水处理
- [ ] 拍照留档

### 9.3 安装后

- [ ] 通电自检通过
- [ ] 串口读数正常
- [ ] 网关能收到该节点数据
- [ ] 记录 RSSI / SNR
- [ ] 核对传感器读数合理性
- [ ] 记录设备序列号与安装位置
- [ ] 更新台账
