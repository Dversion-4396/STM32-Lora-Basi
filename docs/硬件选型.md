## 2 主控芯片

### 2.1 节点 MCU：GD32L233RCT6

| 参数 | 规格 |
|---|---|
| 内核 | ARM Cortex-M23 |
| 主频 | 64 MHz |
| Flash | 256 KB |
| SRAM | 32 KB |
| 封装 | LQFP64 |
| 工作电压 | 1.71 ~ 3.6 V |
| 工作温度 | -40 ~ +85 ℃ |
| **Run 电流** | 约 100 µA/MHz |
| **Sleep 电流** | 约 10 µA |
| **Stop 电流** | **< 2 µA** |
| **Standby 电流** | **< 0.4 µA** |
| 特色外设 | Segment LCD 控制器、TRNG、CAU 硬件加密、LPUART |

**选型理由**：

1. **Stop/Standby 电流极低** —— 这是续航的直接保障，节点 98% 时间在 Standby
2. **内置 Segment LCD 控制器** —— 现场调试可直接读数，且不占用 CPU
3. **TRNG + CAU** —— 报文鉴权，防止伪造上报
4. **LPUART** —— 低功耗串口，可 LPUART 唤醒
5. **国产供货** —— 兆易创新，供应链稳定

### 2.2 网关 MCU：GD32F303

| 参数 | 规格 |
|---|---|
| 内核 | ARM Cortex-M4（带 FPU） |
| 主频 | 120 MHz |
| Flash | 256 ~ 512 KB |
| SRAM | 64 ~ 96 KB |
| 封装 | LQFP48/64/100/144 可选 |
| ADC | 21 通道 |
| 工作温度 | -40 ~ +85 ℃ |

**选型理由**：

1. **算力充足** —— 需同时跑 LoRa 驱动、4G AT 交互、文件系统、MQTT 协议栈
2. **SRAM 更大** —— 缓存与协议栈缓冲区需要
3. **21 通道 ADC** —— 监测机柜温度、电池、各路电源
4. **封装可选** —— 按 IO 数量灵活取舍

### 2.3 为什么不用 STM32

| 对比项 | GD32L233 | STM32L0/L1 |
|---|---|---|
| Stop 电流 | < 2 µA | 约 1~2 µA（相当） |
| 供货 | 国产，稳定 | 受国际供应链影响 |
| 价格 | 更低 | 较高 |
| 生态 | 兼容 STM32 开发方式 | 成熟 |
| 工具链 | Keil/GCC 均可 | Keil/GCC 均可 |

> GD32 在软件层面与 STM32 高度兼容，标准外设库用法几乎一致，迁移成本低。这也是本项目能在 STM32F103 上先做原型验证、再平滑迁移到 GD32 的原因。

## 3 射频模块

### 3.1 SX1262 vs SX1278

| 参数 | **SX1262** | SX1278 |
|---|---|---|
| 频段 | 150 ~ 960 MHz | 137 ~ 525 MHz |
| 最大发射功率 | +22 dBm | +20 dBm |
| **接收电流** | **约 4.6 mA** | 约 10 mA |
| 睡眠电流 | 约 0.6 µA | 约 0.2 µA |
| 灵敏度（SF12, BW125） | 约 -137 dBm | 约 -136 dBm |
| TCXO | 支持 | 通常需外置 |
| 调制 | LoRa / (G)FSK | LoRa / (G)FSK |
| 接口 | SPI | SPI |

**选 SX1262 的决定性理由**：

虽然节点以发射为主，但**下行配置、时间同步与 ACK 都需要开接收窗**。接收电流从 10 mA 降到 4.6 mA，意味着可以放心地把接收窗开得更长，从而提升可靠性而不显著牺牲续航。

此外 **TCXO** 在 -40~+70 ℃ 宽温范围内的频率稳定性，是野外设备可靠通信的前提——晶振频偏会导致收发双方频率对不上，表现为「近距离也收不到」。

### 3.2 法规约束（重要）

470 MHz 属**微功率短距离设备频段**。依据工业和信息化部公告 2019 年第 52 号：

- ✅ 列入目录的设备**无需频率使用许可与电台执照**
- ❌ **不得擅自加大发射功率**
- ❌ **不得额外加装射频功放**
- ❌ **不得擅自更改天线**

因此：

> **模块标称 +22 dBm 的能力必须降额到 +17 dBm 档使用，链路预算按 +17 dBm 计算。**

这不是保守，是合规要求。

### 3.3 常见 LoRa 模块

| 模块 | 芯片 | 频段 | 功率 | 接口 | 备注 |
|---|---|---|---|---|---|
| E22-400T22S | SX1262 | 470 MHz | +22 dBm | UART | 免开发，AT 配置 |
| E22-400M22S | SX1262 | 470 MHz | +22 dBm | SPI | 需自己写驱动 |
| RA-02 | SX1278 | 433 MHz | +20 dBm | SPI | 便宜，但 433 非本方案频段 |
| E32-433T20D | SX1278 | 433 MHz | +20 dBm | UART | 通用透传 |

> 本方案若追求快速验证，可用 E22-400T22S（UART 版）；若追求功耗与灵活性，用 E22-400M22S（SPI 版）自己写驱动。

## 4 传感器

### 4.1 三合一土壤变送器

| 参数 | 典型值 |
|---|---|
| 测量参数 | 体积含水率、温度、电导率 |
| 含水率量程 | 0 ~ 100 %（VWC） |
| 含水率精度 | ±3%（标定后） |
| 含水率分辨率 | 0.1% |
| 温度量程 | -40 ~ +80 ℃ |
| 温度精度 | ±0.5 ℃ |
| 电导率量程 | 0 ~ 20000 µS/cm |
| **供电** | **12 ~ 24 V DC** |
| 输出 | RS485 / Modbus RTU |
| 防护等级 | IP68 |
| 响应时间 | < 1 s |

**关键注意点**：

> 供电 **12~24 V** 这一点常被忽略。节点若用 3.7 V 锂电，**必须增加升压电路**，而升压电路的效率与静态电流会直接吃掉续航。
>
> 本方案的处理：**仅在采样时刻给传感器上电**，上电后等待稳定时间（约 3 s）再读数，采样完成立即断电。

### 4.2 测量原理对比

| 原理 | 方法 | 精度 | 成本 | 抗盐分 | 适用 |
|---|---|---|---|---|---|
| **FDR**（频域反射） | 测介电常数推算含水率 | 中（标定后 ±3%） | 低 | 中 | ★ 大范围布点 |
| TDR（时域反射） | 测电磁脉冲传播时间 | 高（±1~2%） | 显著更贵 | 好 | 科研级 |
| 电容式 | 测电容变化 | 低 | 很低 | 差 | 廉价方案 |
| 张力计 | 测土壤水势 | 中 | 中 | 好 | 需维护 |
| 烘干称重法 | 105 ℃ 烘 24 h | 最高（基准） | 人工成本高 | — | 标定基准 |

**选 FDR 的理由**：成本与体积适合大范围布点，标定后可满足业务精度。

### 4.3 雨量计

| 参数 | 典型值 |
|---|---|
| 类型 | 翻斗式 |
| 分辨率 | 0.2 mm / 0.5 mm |
| 输出 | 干簧管脉冲 |
| 供电 | 无需（无源触点） |
| 承水口径 | 200 mm |

**用途**：除雨量统计外，还作为**事件唤醒源**——强降雨时自动加密上报。

## 7 采购注意事项

1. **射频模块要确认频段** —— 470 MHz 与 433 MHz 不能混用，天线也不通用
2. **传感器要确认供电** —— 12 V 供电的型号需配升压电路，5 V 供电的可以直接用
3. **电池要带保护板** —— 野外无人值守，过充过放风险高
4. **太阳能板要算阴雨天** —— 理论值远远不够，至少 3~7 天自给
5. **天线要匹配阻抗** —— 50 Ω，接头损耗要计入链路预算
6. **认准工业级温度范围** —— -40 ~ +85 ℃，商业级（0~70 ℃）在北方冬季会失效
